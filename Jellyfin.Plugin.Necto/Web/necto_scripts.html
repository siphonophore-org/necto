A script runs its steps when one of its triggers happens. Item kinds, users, and conditions narrow which events it runs for. Steps can message or control sessions, change items and users, call webhooks, queue server tasks, or run a command at any path the server can reach.
General
Triggers
The script runs when any checked trigger happens. Search to narrow the list.
Item kinds
Runs only for items of these kinds. Leave blank for every kind.
Runs once per pause, after the session has stayed paused this long.
Runs once per playback, after this much playing time. Pauses do not count.
Runs once per playback, when it goes from below this percentage to at or past it.
Runs when the number of active streams rises to this many. The event is the stream that reached it.
Runs when the number of transcoding streams rises to this many. The event is the stream that reached it.
Webhook
Send a POST here with a Jellyfin API key from Dashboard, API Keys. The address picks the script and the key proves the caller may run it. A request with either one missing is refused. Query parameters and JSON fields arrive as {{WEBHOOK_NAME}}. 

                                        
                                    

                                


                                

                                    
Schedule

                                    

                                        

                                            A script on a schedule runs as a Jellyfin scheduled task. Once you save, it is listed under
                                            Dashboard, Scheduled Tasks
                                            in the Scripts section, under this script's name and description. Set when
                                            it runs there, or run it by hand. It only runs on its schedule while the script is enabled.
                                        

                                        

                                    

                                

                            

                        


                        
                        
                        

                            
Groups

                            

                                
Runs for the members of the groups that run it. On playback, any of the session's users counts. Triggers without a user ignore this.

Steps

                            

                                
Run in order. Drag a step or use the arrows to move it. A failed step stops the rest unless it continues on error.

                                

                                

                                

                                

                                    
                                    

                                        
                                    

                                

                            

                        


                        
                        

                            
Secrets

                            

                                

                                    Tokens and passwords this script uses. Use one as {{SECRET_NAME}} in a step,
                                    or $JF_SECRET_NAME in a command. Values are encrypted on the server, never
                                    shown again, left out of exports, and masked wherever they appear in the history.
                                

                                

                            

                        


                        
                        

                            
Behavior

                            

                                

                                    
                                    
                                    

                                        A schedule, a webhook, and Run now have no item or user of their own. Running for each
                                        gives the steps one: every library item of the script's item kinds, or every user, that
                                        passes its conditions. A trigger that already has one runs once as usual.
