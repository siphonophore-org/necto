Runs a script's steps when one of its triggers happens.

General
Triggers
Runs the script when any checked trigger happens.
Item kinds
Runs only for items of these kinds. Leave blank for every kind.
Runs once per pause, after the session has stayed paused this long.
Runs once per playback, after this much playing time. Pauses do not count.
Runs once per playback, when it passes this percentage.
Runs when the number of active streams rises to this many.
Runs when the number of transcoding streams rises to this many.
Webhook
Send a POST here with a Jellyfin API key. Query parameters and JSON fields arrive as {{WEBHOOK_NAME}}.

                                                    
                                                

                                            


                                            

                                                
Schedule

                                                

                                                    
Runs as a Jellyfin scheduled task once saved. Set when it runs in Dashboard, Scheduled Tasks.

                                                    

                                                

                                            

                                        

                                    


                                    
                                    
                                    

                                        
Groups

                                        

                                            
Sets which users the script runs for. Administrators run every script.
