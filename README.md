A Jellyfin plugin that keeps your server reachable, secure and healthy. It brings requests and issue reports, invites, groups, a reverse proxy with certificates, DDNS, WireGuard, scripts, custom pages, storage monitoring, and notifications into one page, with every permission set on groups.

## The Name

A [nectophore](https://en.wikipedia.org/wiki/Siphonophore#Nectophores) is one of the "medusae that assist in the propulsion and movement of some siphonophores." Necto is the part of the colony that keeps a server moving: reachable, secure and healthy.

## Status

Necto is being built, on the unstable channel only. The docs are at [necto.siphonophore.org](https://necto.siphonophore.org), and [docs/Plan.md](docs/Plan.md) lists what it holds and the order it is built in.
